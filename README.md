# Proyecto Web Estático - Frontend

Este repositorio contiene el código fuente de una página web estática multicapa, desarrollada como parte de mi portfolio de desarrollo web. El proyecto demuestra el uso práctico de maquetación con HTML5 y diseño de interfaces con CSS3 puro, estructurando el contenido en múltiples vistas interconectadas.

## 🚀 Descripción del Proyecto

El objetivo de esta práctica es construir un sitio web completo desde cero sin el uso de frameworks externos, asegurando una comprensión sólida de los fundamentos de la web. La temática elegida para el desarrollo de la interfaz aborda un catálogo informativo (en este caso, perfiles de integrantes de un grupo musical), lo que permite trabajar con diferentes estructuras de datos visuales.

### Funcionalidades Técnicas Destacadas:
* **Navegación Multicapa:** Enrutamiento funcional entre la página principal (`index.html`) y múltiples páginas de detalle.
* **Diseño Modular de Estilos:** Separación de hojas de estilo (`style.css`, `styleIntegrantes.css`, `styleformulario.css`) para mantener un código escalable y organizado.
* **Formularios Estáticos:** Implementación de interfaces de captura de datos de usuario con validación HTML nativa.
* **Estructura Semántica:** Uso adecuado de etiquetas HTML5 para mejorar la accesibilidad y el SEO básico.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructurado semántico del contenido.
* **CSS3:** Maquetación, tipografía, uso de selectores avanzados y diseño responsivo básico.
* **Git / GitHub:** Control de versiones y despliegue continuo (CI/CD básico mediante GitHub Pages).

## 🗂️ Estructura del Repositorio

El proyecto mantiene una estructura plana y accesible para servidores web estáticos:

* `index.html` - Página de inicio o *Landing Page*.
* `02.BangChan.html` ... `09.Seungmin.html` - Vistas detalladas de contenido dinámico.
* `10.Formulario.html` - Interfaz de contacto/registro.
* `imágenes/` - Directorio de recursos gráficos (*assets*).
* `*.css` - Hojas de estilo modulares aplicadas a diferentes secciones.
